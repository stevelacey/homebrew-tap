# Steve's Homebrew Tap

```sh
brew tap stevelacey/tap
```

## Formulae

- [proton-vpn-cli](https://github.com/stevelacey/proton-vpn-cli-macos): the Proton VPN CLI, forked for macOS
- [wifi-cli](https://github.com/stevelacey/wifi-cli-macos): manage Wi-Fi connections on macOS

## Casks

- [proton-vpn-menubar](https://github.com/stevelacey/proton-vpn-menubar): a menu bar app for Proton VPN
